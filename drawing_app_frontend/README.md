# Drawing App Frontend (React)

## Features
- Canvas drawing (brush)
- Eraser mode (destination-out)
- Brush size slider
- Color picker
- Undo / Redo (image snapshot history)
- Clear canvas
- Export PNG
- Import image as background
- Zoom / Pan (view transform)
- Responsive layout (sidebar on desktop, stacked layout on mobile)

## Run
```bash
npm install
npm start
```

App runs on port `3000`.
